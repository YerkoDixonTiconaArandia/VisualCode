# Proyecto Tienda de Tenis

Este proyecto es una tienda en línea dedicada a la venta de tenis deportivos. A continuación se describen los archivos y su propósito dentro del proyecto.

## Estructura del Proyecto

```
tienda-tenis
├── src
│   ├── index.html          # Página principal de la tienda
│   ├── catalogo.html      # Página que muestra el catálogo de productos
│   ├── css
│   │   └── estilos.css     # Archivo de estilos CSS
│   ├── js
│   │   └── catalogo.js     # Archivo de JavaScript para la lógica del catálogo
│   └── data
│       └── productos.json   # Archivo JSON con los datos de los productos
├── README.md               # Documentación del proyecto
```

## Instrucciones de Configuración

1. **Clonar el Repositorio**: Clona este repositorio en tu máquina local.
   
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```

2. **Navegar a la Carpeta del Proyecto**: Accede a la carpeta del proyecto.

   ```bash
   cd tienda-tenis
   ```

3. **Abrir el Archivo HTML**: Abre `src/index.html` en tu navegador para ver la página principal de la tienda.

4. **Visualizar el Catálogo**: Para ver el catálogo de productos, navega a `src/catalogo.html`.

## Notas

- Asegúrate de tener un servidor local si deseas probar las funcionalidades de JavaScript que cargan datos desde el archivo JSON.
- Puedes personalizar los estilos en `src/css/estilos.css` para ajustar la apariencia de la tienda según tus preferencias.
